# coffeecient

A clickable mobile prototype of coffeecient, an Indian café app: order ahead (delivery, pickup, at the café), beans and gear shop, live order tracking, rewards and scratch cards, Coffee Passport, Learn, a caffeine tracker and a coffee journal.

This repo holds the built prototype as one static `index.html` (React + Tailwind, bundled). Open it in a browser, or visit the Vercel deployment. Add `#newuser` to the URL to start as a new user.
